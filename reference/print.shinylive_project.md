# Print method for shinylive_project objects

Displays the project sharelink and the files it carries.

## Usage

``` r
# S3 method for class 'shinylive_project'
print(x, ...)
```

## Arguments

- x:

  shinylive_project object

- ...:

  Additional arguments (ignored)

## Value

The `shinylive_project` object it was handed, returned invisibly, so it
can be passed straight on. Called for the summary it prints, which
covers the URL, the files the project carries, the engine, and the mode.
See
[`shinylive_project()`](https://r-pkg.thecoatlessprofessor.com/livelink/reference/shinylive_project.md)
for the entries the object holds.
